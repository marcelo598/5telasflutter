# Projeto 5 Telas - Flutter

Projeto acadêmico desenvolvido em Flutter contendo cinco telas:

1. Tela Inicial
2. Perfil
3. Produtos
4. Favoritos
5. Configurações

## Como executar

No terminal, dentro da pasta do projeto:

```bash
flutter pub get
flutter run
```

Para verificar o ambiente:

```bash
flutter doctor
```

## Estrutura

- `lib/main.dart` - inicialização do aplicativo e rotas
- `lib/screens/` - cinco telas do aplicativo
- `pubspec.yaml` - configuração e dependências do projeto
